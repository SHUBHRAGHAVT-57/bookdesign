# KeyTurn — a focused practice studio

The user approved retaining the existing identity while overhauling weak UI.

- Preserve original passages, the two-page typing/recall/review loop, deep green and paper/ink contrast.
- Use a calm off-white working surface and white paper. Green identifies the current task and primary action. No simulated leather, noise grain, gilt frames, or decorative ribbons.
- Geist is the local interface face; a readable serif is reserved for passage text. Controls and metrics use the interface family and tabular numerals.
- The opening view is a practice library with real passage contents and one clear start action. The active view exposes the session, current passage, progress and settings without a marketing hero.
- Controls use consistent 44px minimum targets, visible focus, semantic states, and restrained 160–220ms feedback. The authored page turn remains optional through reduced motion.
- Mobile stacks the two practice pages, preserves readable copy and keeps controls usable at 375px. No invented progress, cloud saves or performance claims.
